# File Processing Toolkit

A practical toolkit for file automation tasks: hashing, renaming previews, extension grouping, and text extraction helpers.

## Features

- Scan folders safely
- Group files by extension
- Create SHA-256 hashes
- Generate rename previews without changing files

## Stack

`Python` · `C#` · `Bash` · `Files Automation`

## Run

```bash
python python/file_report.py .
```
