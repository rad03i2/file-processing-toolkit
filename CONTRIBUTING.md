# Contributing

Contributions are welcome. Use Python 3.10+, keep the runtime dependency-free where practical, add tests for behavioral changes, and preserve safe-by-default file operations.

1. Fork and create a focused branch.
2. Install with `python -m pip install -e .`.
3. Run `python -m unittest discover -s tests -v`.
4. Open a pull request describing behavior and tests.

Do not include personal files, credentials, generated artifacts, or destructive defaults.
